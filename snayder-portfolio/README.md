# Snayder Portfolio

Portafolio profesional de Snayder Cedeño, Desarrollador Full Stack Junior.

## Tecnologías

- React, Vite y TypeScript
- Tailwind CSS
- React Router

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run lint
npm run build
```

## Estado actual

La página principal, navegación responsive, rutas de casos de estudio, página 404, descarga de CV, imagen Open Graph y sitemap están implementados. El sitio está publicado en [snayder-portfolio.vercel.app](https://snayder-portfolio.vercel.app).

## Estructura relevante

- `public/cv/`: CV descargable desde el sitio.
- `public/images/`: recursos visuales del perfil, proyectos y Open Graph.
- `src/components/`, `src/data/`, `src/pages/`, `src/routes/`, `src/styles/`, `src/types/`: código fuente organizado por responsabilidad.

Los archivos internos de `docs/` se conservan localmente y se excluyen del repositorio y del despliegue.
